# Export as Blend v1.3.0 - Blender 插件

将 Blender 场景中的集合导出为单独的 .blend 文件，自动清理变换和未使用数据。

## 功能

- **选中 → 各自集合**：将选中物体各自放入以自己名字命名的集合
- **按集合导出**：只导出包含**资产标记**的集合，每个集合生成一个纯净的 .blend

## 导出时自动处理

- ✅ 物体重置到世界原点（位置/旋转/缩放归零）
- ✅ 资产标记保留（仅物体，材质不会被标记为资产）
- ✅ 清理未使用的材质和孤立数据块
- ✅ 文件名自动过滤特殊字符
- ✅ 失败的集合不影响其他集合导出
- ✅ 支持物体名含特殊字符

## 使用方法

### 安装
1. Blender → Edit → Preferences → Add-ons
2. 点击右上角 **Install**
3. 选择本插件 .zip 文件
4. 勾选启用 **"Export as Blend"**

### 操作步骤
1. 在 3D 视图中按 **N** 打开侧栏
2. 找到 **"组织导出"** 标签页
3. **整理**：选中模型，点击 **"选中 → 各自集合"**
4. **标记资产**：选中模型右键 → **Mark as Asset**（只导出含资产标记的集合）
5. **导出**：点击 **"按集合导出"**，选择输出目录

## 技术细节

使用后台 Blender 进程（--background --factory-startup）处理导出，通过临时 JSON 文件传递数据。
